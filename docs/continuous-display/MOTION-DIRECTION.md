# Motion direction R2

Mother's Love is a reference for polished animated presentation, not an asset or data source. This pass introduces distinct, gentle entrance choreography and slow background movement for the announcement, date-specific schedule, event and fictional campaign layouts. No unapproved text or character assets are imported.

Playback remains silent. Motion never determines scheduling, media fallback or content eligibility. Reduced-motion OS preference, manual Still mode in the lab, and cut transitions disable animations. Animations use CSS with no accumulating JS animation instances. Real TV/iPad performance and readability remain to be tested before any live release.

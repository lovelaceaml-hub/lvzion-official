# LV Zion Official

An independent, phone-first application. Existing LV Zion systems are references only and remain untouched.

## Member-foundation status

The development branch `feature/member-system-secure-r1` contains the member foundation, independent organization/department/technical permissions, history-preserving member management, onboarding, invitation delivery and verified recovery. Draft PR #2 remains unmerged, stacked on the mobile-prototype draft PR #1.

- `/`: preserved original home concept.
- `/member-preview`: interactive fictional My Week / My Group / Manage / Profile. All demo changes are in memory; no real login is simulated as authenticated access.

- `/request-access`, `/sign-in`, `/auth/continue`, `/activate`, `/reset-password`: implemented account workflows.

The new Supabase project now has three schema migrations and 17 RLS-protected tables, but no hosted members or Auth users. Hosted test-account provisioning was blocked; hosted access remains off. No real invitations, real member imports, original-system changes, production-site release or domain work occurred.

## Development

Use Node 24.

```sh
npm ci --ignore-scripts
npm run dev
npm run build
npm run test:browser
```

The build runs strict route/type checks, 42 Node tests, and 75 disposable PostgreSQL assertions before Next.js builds. Browser tests require installed Playwright Chromium. The real local Auth/PostgREST/SMTP suite has separate reproducible setup documented in `docs/ONBOARDING-COMPLETION.md`; its 47 assertions were run successfully on a fresh local stack.

Use the three canonical migration files only. Hosted migration IDs were generated by MCP and have a recorded mapping; reconcile that ledger before using CLI db push. No seed or test bootstrap file belongs in production.

The permanent domain `lvz.app` remains paused. The official individual application modules are not yet selected. This branch is not a congregation-ready production release.
